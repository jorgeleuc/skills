# Diseño sin relleno

Principio: cada palabra y cada elemento en la pieza tiene que tener una razón. Si no aporta al mensaje, no va.

## Aplica a

- Posts, stories y anuncios para redes
- Presentaciones y slides
- Web, landings, mockups y artifacts HTML
- Impresos: afiches, flyers, banners, tarjetas

## Texto

Se usa el texto que entrega el usuario. Se permite agregar solo texto mínimo funcional: un CTA o un dato clave (precio, fecha, contacto) cuando la pieza no funciona sin él. Nada más.

Prohibido agregar por cuenta propia:

- Eslóganes, taglines o frases inventadas ("Tu mejor aliado", "Innovación que transforma").
- Etiquetas decorativas: "NUEVO", años, kickers o eyebrows sobre el título, numeritos de sección, subtítulos que repiten el título.
- Emojis, hashtags e íconos de relleno.
- Pies y créditos: footers, "Diseñado por", fechas, URLs o redes que no se pidieron.
- Texto placeholder (Lorem ipsum, "Tu texto aquí").

Si un texto entregado es muy largo para la pieza, se señala y se propone una versión corta; no se rellena ni se inventa otro.

## Visual

- Sin formas, líneas, degradados, patrones, sombras o íconos que no cumplan una función.
- Espacio en blanco antes que decoración.
- Una jerarquía clara: un mensaje principal por pieza.
- Pocos colores y una o dos tipografías.

## Excepciones

- Elementos obligatorios de marca o legales (logo, disclaimers regulatorios) sí van, aunque no se pidan, si la pieza los requiere.
- Si el usuario pide explícitamente un adorno, se respeta.

## Revisión antes de entregar

Recorrer la pieza elemento por elemento y preguntar: ¿el usuario lo dio o es funcional? Si la respuesta es no, se quita. Al entregar no se explica la pieza ni se justifica el diseño; se entrega y listo.
