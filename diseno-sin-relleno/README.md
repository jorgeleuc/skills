# Diseño sin relleno

Skill para Claude que evita textos y elementos de adorno en piezas gráficas: posts, anuncios, presentaciones, web, mockups e impresos.

## Qué hace

- Usa solo el texto que vos das. Como mucho agrega un CTA o un dato clave si la pieza no funciona sin eso.
- No inventa eslóganes, etiquetas, emojis, hashtags, footers ni créditos.
- Aplica lo mismo a lo visual: nada de formas, degradados o íconos que no cumplan una función.

## Cómo instalarla

1. Descargá este repo como ZIP o solo la carpeta con el `SKILL.md`.
2. En Claude, andá a la configuración de skills y subí el archivo.
3. Listo. Se activa sola cuando pedís cualquier pieza gráfica.
